# Assets Directory

This folder contains all media and downloadable files for your portfolio.

## Structure

```
assets/
├── cv.pdf              # Your CV (add your file here)
├── images/
│   ├── projects/       # Project screenshots
│   ├── gallery/        # Photography portfolio
│   └── profile/        # Profile pictures
├── documents/          # Additional documents
└── files/              # Downloadable files
```

## Guidelines

- **CV**: Place your latest CV as `cv.pdf`
- **Images**: Keep images optimized (max 2MB per image)
- **Formats**: Use .jpg for photos, .png for graphics
- **Organization**: Keep files organized in subdirectories

## Recommended Image Sizes

- Hero Section: 1920x1080 or wider
- Project Cards: 600x400
- Gallery Images: 1200x800
- Profile Picture: 500x500
